# StockSense Frontend

Frontend web dashboard and client interfaces for the StockSense platform.

## Architecture & Roadmap
- **Phase 5:** Gateway and Frontend Dashboard MVP (Live charts, backtest visualizer, candle viewer)
- **Phase 7:** Strategy Writing (rule builder, web code editor, sandbox controls)
- **Phase 8:** Optimization and Robustness (parameter sweep dashboards, walk-forward visualizer)
- **Phase 9-11:** Signal runner, paper trading console, order book visualization, testnet risk kill-switch

## Integration
Consumes backend microservices through the API gateway and OpenAPI contracts defined in `Stock_Sense_Backend/contracts/openapi/`.
